# Jost local

Jost v20, arquivo variável normal (eixo de peso 100–900), subconjunto Latin com os acentos usados em PT/EN. Extraído sem alterações de `@fontsource-variable/jost@5.3.0`, arquivo `files/jost-latin-wght-normal.woff2`.

Origem: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/jost), distribuída por [Fontsource](https://www.npmjs.com/package/@fontsource-variable/jost/v/5.3.0). A [licença SIL OFL 1.1](OFL.txt) acompanha o binário e deve permanecer em redistribuições.

`next/font/local` gera o CSS, faz preload e serve WOFF2 no mesmo domínio, com `display: swap`. Não há consulta ao Google no build ou durante a visita. Somente o estilo normal usado pela fundação foi incluído.
